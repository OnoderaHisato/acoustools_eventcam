# 次の計測（2026-09-20 作成）

目的は 2 つ: (A) この装置の水平の力の上限を数字にする、(B) 位置依存の外乱 w を経路ごとではなく 3 次元の場として持つ。
優先順は 1 → 2 → 3。どれも既存の取得経路でそのまま流せる（1・2 は取得側の上限内、3 はステップ経路）。

## 1. 外乱の補償の実証（7 Hz）— `ff_heart/`

`heart_s7_f7_OFF` / `heart_s7_f7_OFFW`（所望 − w）/ `heart_s7_f7_C_delay_inverse` / `heart_s7_f7_CW`（先読み＋逆モデル − w）を各 1–2 本。
10 分以上休ませた直後に、前後を kcheck（x・y・z）で挟む。期待は 60–95 Hz 帯の揺れ（x 0.28、y 0.50 mm）が半分以下。
10 Hz 版（`heart_s7_f10_OFFW` / `CW`）は最大加速度 104k / 107k mm/s² で、取得側の上限 100k を 110k 以上に上げたときだけ流せる。

## 2. 外乱 w の面走査 — `w_scan/`（`make_w_scan.py`、図 `wscan_XZ_preview.png`）

渦巻き（半径 0 → 9.2 mm → 0、1.5 回/s、14 s、最大 87 mm/s・0.8k mm/s²、補償なし）。この速さでは共振は立たず、粒子は w をそのままなぞる。
渦の間隔は実効 0.7 mm（w の最短周期 2.5 mm の半分以下）。ハート 7 mm の全域を含む。

| 指令 | 面 | 用途 |
|---|---|---|
| `wscan_XZ_a`, `wscan_XZ_b` | XZ（y = 0） | 最優先。a は反時計回り、b は時計回り |
| `wscan_YZ_a`, `_b` | YZ（x = 0） | |
| `wscan_XY_a`, `_b` | XY（z = 0） | |
| `wscan_XZyp4_a/b`, `wscan_XZym4_a/b` | XZ を y = ±4 mm にずらす（半径 8 mm） | 3 次元の補間用 |

検定できること:
- a と b は同じ場所を逆向きに通る → w が「位置だけの関数」か「進む向きにも依る」か。
- XZ 面の場から**ハート経路上の w を補間**し、既に測った `ff_heart/w_field_heart_xz.npz` と比べる → 別の形への汎化の最初の検証（追加計測なしで判定できる）。
- 場ができれば、カーディオイドや円の 10 Hz に対する補償指令を計測なしで作れる。
撮り方: 各面 a → b を続けて。前後に kcheck は不要（ゆっくりなので剛性に依らない）。時間があれば XZ を 2 回（再現性）。

## 3. 水平の力の上限 — `large_step/`（`make_large_step_trajectory.py`、エクスポート `export_large_step/`）

1 軸だけを 0 → +S → 0 → −S → 0、12 ジャンプ、ホールド 0.4 s、5.4 s。`vzrstep_XL12 / XL15 / XL18 / XL20`（x、1.2 / 1.5 / 1.8 / 2.0 mm）と `vzrstep_YL12…YL20`（y）。
1 mm 以下では積 k_x = ar·vxr しか決まらないが、1.5 mm 以上で飽和長 vxr が分かれ、水平の力の上限 A_r = k_x / vxr が出る。
模擬（k_x 0.25、ノイズ 0.01 mm）では全段で保持、vxr の推定は真値 0.5 / 1.0 / 1.47 に対し 1.5 mm で 0.52 / 1.00 / 1.47（±0.01）。
**小さい段から順に上げること**: 真の飽和長が 1.47（力の最大 1.1 mm）なら 1.8–2.0 mm のジャンプは力の最大を超えた位置から戻ることになり、
模擬では保持でも実機では余裕が薄い。XL12 → XL15 で粒子の戻り方が鈍くなったら、そこで止める（それ自体が答えになる）。
2 mm は 8 月、1.7 mm は 9/16 に保持済み。取得 PC でエクスポータを実行し直すのが確実（manifest は絶対パス）:
`python ../vzr_step/export_vzr_step_for_acquisition.py --commands commands --out export_large_step`。解析は `vzr_step/vzr_step_fit.py`（水平の段だけ当てる）。
