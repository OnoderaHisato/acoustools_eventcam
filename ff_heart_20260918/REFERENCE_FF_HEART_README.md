## 設計の要点

- 所望軌道は取得側 `generate_cycle_positions` mode 4 と同じ式（x = s·sin³θ, z = s·(13cosθ−5cos2θ−2cos3θ−cos4θ)/13, XZ 面）。
- **クリップは掛けていない**。純遅延の先読みは指令を r から 0.6 mm 離すが、トラップ−粒子の距離は
  0.3 mm 程度で、脱出とは無関係（従来の |u−r| ≤ 1.0 mm クリップは不要。掛けるならトラップ−粒子距離に）。
- 逆モデルの k・γ は 9 月ブロック最初の run の値（x 0.30 / 0.040、z 3.1 / 0.024）。**剛性は稼働
  10 分で 25–35% 落ちる**ので、run 前後に短いステップを撮って k を確認する（HANDOFF「連続稼働による剛性低下」）。
- 非線形（sin）補正は最大 3% なので入れていない。この軌道は力最大の ≤41%（線形域）。
- 速度 745 mm/s・加速度 93,000 mm/s² — 取得側の safety_limits（plan B: 400 mm/s）を超えるので緩和が必要。

## 時間軸の扱い（重要）

指令は PAT 時間（公称 10 kHz）で作ってある。実測ではトラップ事象がカメラ時間で
`t_cam = t_pat·(1 + 182e-6) + τ0` に現れる。評価では **`time_cam_expected_sec` の時刻で
測定位置を読み、同じ行の `r` と比較する**こと（従来の「LED で原点合わせのみ」だと 8 s 末で
1.1 mm の見かけの遅れが乗る）。表示を実時間で厳密に 10.000 Hz にしたければ
`--exact-realtime`（PAT 側の周波数を 10.00182 Hz にする）。

どちらのクロックが正しいかは未確認。記録の**末尾**にも LED 同期を入れれば run ごとに比が測れる。

## 計測プロトコル（提案）

1. ウォームアップ 10 分、または各 run 前に 5 分休止（どちらかに統一）。
2. サンドイッチ: 各 run の直前直後に x/z の短いステップ（各 6 ジャンプ、~15 s）→ k の確認。
3. 順序: OFF → A → C → C → A → OFF（往復で時間と連続稼働による剛性低下を交絡させない）、各 8 s、間隔一定。
4. 評価: `time_cam_expected_sec` で比較した追従誤差 rms。**成功基準 = 再現しない残差の床
   0.15–0.25 mm に届くこと**。OFF の予想は 0.5–1 mm 級（遅延 0.6 mm ＋ 時間軸）。
5. A と C の差は 0.1 mm 程度と予想。差が出なければ A（1 パラメータ）で十分。

## 予測（同定モデルによる模擬、`heart_s7_f10_ff_prediction.png`）

同定モデル（sin 力場、τ0 0.8 ms、クロック差 182 ppm を含む）で前進積分し、カメラ時間で
所望軌道と比較（ランプ後 0.7–2.0 s）。プラントと逆モデルの k・γ が一致した**理想値**。

| 設計 | rms [mm] | max [mm] | 備考 |
|---|---|---|---|
| OFF | 0.53 | 0.80 | 遅延 0.6 mm ＋ 動力学 0.3 mm |
| A（先読みのみ） | 0.19 | 0.33 | 残るのは動力学の遅れ Δ ≈ 0.28 mm |
| C（先読み＋線形逆モデル） | **0.03** | 0.05 | モデルが正しければほぼゼロ |

- 狭いトラップ（vxr 1.47）でも広いトラップ（0.81）でも同じ値（線形域なので飽和形状は効かない）。
- 実機では**再現しない残差の床 0.15–0.25 mm** が加わるので、C でも 0.2 mm 前後が現実的な到達点。
- 連続稼働による剛性低下で k が 25% ずれると C の残差は A の 1/4 程度（≈0.05 mm）残る。
- トラップ−粒子の最大距離は 0.33 mm（力最大 1.07–1.9 mm に対し十分な余裕、脱出なし）。

### 残った再現誤差の正体（周波数で見ると 3 つに分かれる）

| 成分 | 大きさ（再現誤差の帯域 rms） | 中身 | 対策 |
|---|---|---|---|
| z の 10–30 Hz | OFF 0.31–0.39 → 先読みが合えば 0.10 | 純遅延だけ | τ0 を合わせる（A で十分） |
| x の 10–30 Hz | OFF 0.29–0.43 / A 0.25–0.28 / C 0.19 | 30 Hz の動的ゲイン 17%（×1.75 mm = 0.30）＋遅延。C で半減 | 逆モデル（k を直前の kcheck に合わせる） |
| x と y の 70–90 Hz | x: OFF 0.27–0.38 / A 0.19–0.28 / C 0.12–0.22、y: 0.17–0.35（全設計） | **水平トラップ共振（63–83 Hz、Q≈10）の励起**。指令には 40 Hz 超の成分が無い（x は 1・3 次、z は 1–4 次だけ）ので、弱い加振が共振で 5–10 倍に増幅されている | 未解決（下記） |

70–90 Hz の加振源の候補: ①力の非線形（sin）が作る高調波（見積もり ≈0.1 mm）、②音場の位置依存
（λ/2 = 4.3 mm 周期のリップルを 500 mm/s で横切ると 60–120 Hz、必要な振幅は 0.05 mm 程度）、
③水平面内の主軸が x/y からずれていることによる x→y 連成。y は指令していないのに x と同じ帯域で
同じ大きさだけ揺れており、1 軸ごとの線形モデルでは説明できない（ハート run への直接当てはめでも
再現誤差の説明率は 39–79%）。切り分けには周回周波数を変えた OFF（例 8 Hz・5 Hz）が有効:
誤差が「80 Hz に居座る」なら共振選択、「高調波次数に居座る」なら空間リップル。

1. ~~τ0 の状態で指令を選ぶ~~ → 訂正 1 のとおり τ0 は 0.8–0.9 ms で一定。`A_delay` / `C_delay_inverse`（0.8 ms）を使い、LED を明るく保つ。

### 追加した指令（2026-09-19）: 周回周波数を変えた補償なし

`heart_s7_f5_OFF`（max a 23k mm/s²）、`heart_s7_f7_OFF`（46k）。70–90 Hz 残差の加振源の切り分け用。

### 訂正 1: 「τ0 の 2 状態」は PAT の遅延ではなく、開始 LED の検出条件のアーチファクト

`pat_camera_timing.json` の LED 検出イベント数（`pat_start_led.peak_count`）と見かけの τ0 が完全に連動していた:

| 期間 | LED peak_count | kcheck_z の τ0 | OFF の実効遅れ |
|---|---|---|---|
| 9/18 20:14–21:10 | 128–388（弱い） | 0.24–0.35 ms | +0.39 ms |
| 9/18 21:21, 21:22, 23:21?, 23:22?, 23:29 | 46–47（**不検出**、ノイズを誤検出） | 解析不能 | — |
| 9/18 21:25–9/19 00:13 | 995–2661（強い） | 0.74–0.80 ms | +0.90 ms |

LED が弱いと立ち上がりの検出が約 0.5 ms 遅れ、時刻原点が後ろにずれて遅延が短く見える（イベントカメラは低コントラストほど
画素の応答が遅い）。LED が十分強い（peak ≥ 1000）とき τ0 = 0.8–0.9 ms で、9/16 の 0.75–0.9 ms とも一致する。
→ **真の純遅延は 0.8–0.9 ms。最初の設計値 0.8 ms が正しく、0.3 ms 用に作り直した A03 / C03 は不要だった**（私の早合点）。
A03 / C03 は高 LED 期に撮られ、実効遅れ +0.60 ms（= 0.9 − 0.3）で補償不足になっている。
- 取得側への要望: LED を明るく保つ（peak ≥ 1000 を目安）。`peak_to_threshold_ratio < 3` は不検出として撮り直す。
- 不検出 run の救済: 新形式の JSON には PC 側の予想 onset があり、正常 run では (LED − 予想) = +8.11 ms（sd 0.02 ms、n=3）。
  Miyabi の `ffheart_time_origin.py` が「予想 + 8.11 ms」で原点を復元する（OT-ident① に適用、復元後の実効遅れ +0.92 ms は ② の +0.83 と整合）。

- **周回を半分の速さにしても共振帯（60–95 Hz）の誤差は消えない**（x 0.41、y 0.35）。力の非線形が源なら振幅は f⁶ で 1/64 になるはず → **棄却**。
  5 Hz の指令は 20 Hz 以下の成分しか持たない（x は 5・15 Hz、z は 5–20 Hz）。
- **静止中は揺れていない**: kcheck のホールド中（指令一定、ジャンプの 0.6 s 後以降）の 60–95 Hz 帯は x 0.018 / y 0.016 mm。
  ハートを回っている間は x 0.28–0.43 / y 0.28–0.52 mm で **15–30 倍**。トラップが空間を動くことが加振になっている。
- 全 35 ループ（5 Hz）で波形がぴったり重なる（非再現 0.16 mm）→ 経路上の位置で決まる決定論的な外乱。指令していない y にも同じ大きさで出る。
- 鉛直共振帯（230–320 Hz）の z は、静止 0.010 → 5 Hz 0.009 → 7 Hz 0.016 → 10 Hz 0.050 mm と速さで増える。
  時間周波数 = 空間周波数 × 速さなので、外乱は mm スケールの空間構造を持つ（80 Hz で見ているのは 5 / 7 / 10 Hz でそれぞれ周期 3.1 / 4.4 / 6.2 mm、
  λ/2 = 4.3 mm と同じ桁）。候補は反射や有限アレイによる音場のリップル、位相の量子化によるトラップ位置の段差。今のデータでは区別できない。
- 空間の低次（n ≤ 6）の歪みは速さに依らず同じ形（5 Hz と 7 Hz の相関 0.96、10 Hz とも 0.77–0.85）: x 0.14 mm、z 0.09 mm の**静的な歪み**が別にある。
- → **残差は「トラップ位置の関数」**（決定図の ④ の条件）。モデルで言えば平衡点のずれ場 w(u): `p̈ = K(u + w(u) − p) − γṗ`。
  w は 0.03–0.05 mm 程度でも水平共振（Q ≈ 10）で 0.3–0.5 mm になる。sin 力場のパラメータ（vxr, vzr）をいくら合わせても消えない。
- 次の計測: `heart_s7_f1_OFF` / `heart_s7_f2_OFF`（14 s、1 Hz と 2 Hz、補償なし）。1 Hz なら mm スケールの w は 12 Hz 以下の
  時間変化になり共振の増幅なし（ゲイン ≈ 1）で粒子がそのまま w(u) をなぞるので、**w を直接測れる**。それを共振の伝達関数に通して
  5 / 7 / 10 Hz の共振帯の誤差が再現できれば仮説が閉じ、指令から w を引く補償（u′ = u − w(u)）の設計に進める。

## 1 Hz / 2 Hz の補償なし（XZ 面・YZ 面、2026-09-19 17:42–18:48）— 外乱 w を直接測って仮説が閉じた
