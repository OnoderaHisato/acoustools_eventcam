# 24.8 kg/m³・直径10 mm球の再最適化

元ファイルを上書きせず、このフォルダだけに作業コピー・依存関係・新結果を保存しました。

密度24.8 kg/m³、半径5 mm、球内音速1052 m/s、元パッケージ保存波長からの音速約343 m/s、
P_ref=3.4、素子半径4.5 mm。重力目標127.385299 µNです。
500更新のうち、復元性を満たし力誤差が最小だった反復15の位相を選びました。
最終反復500そのものではありません。元v3の目的関数は力一致と強い負の力勾配のトレードオフがあり、
最小総損失の反復が最小力誤差になるとは限りません。

保存位相と評価力が1更新ずれる問題を新しい入口側で解消し、更新前の評価に対応する複素位相を保存しました。
NPYを読み戻したときの力・Jacobian一致、3×3行列の固有値、展開次数10/12/16、差分幅0.30/0.15 mm、
NumPy/PyTorch力計算の一致を検証しています。
再評価Fzは約126.1655 µN（目標との差約−0.96%）、局所力勾配行列の固有値実部は全て負です。
これはモデル上の原点近傍の診断であり、厳密な平衡点での安定性や実機浮揚の実証ではありません。
