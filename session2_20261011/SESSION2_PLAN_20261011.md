# 計測セッション 2 の計画（2026-10-11 作成）— 学習軌道を多様にする

目的: 2026-10-10 の冷却後の再計測（V15c、130 本）に、形・周波数・大きさ・3 次元の動きを広げた学習軌道（`pinn_optitrap/measurement_plan/ff_diverse/`、37 本）を足し、u → p の模型（M1 系）が形に依らず当たるかを確かめる土台を作る。**計測は 2026-10-11（今日）にユーザーが行う（ユーザーの決定、同日）。** 設計の中身・上限の検査・目的の表は `ff_diverse/README.md`。

## 前提（V15c と同じ状態で撮る）

- 15 V、ファン ON のまま（ブロック 2 の定常。V15c では 19:41 以降 k_x 0.231 → 0.229 で定常、k_z は +7 % 動いた。`nn_embed/results/v15c/kcheck_timeline.md`）。
- **粒子は替えない**（替えたら時刻を記録。共振帯の揺れが粒子で決まる可能性があるため、学習データの中では 1 個に揃える）。
- 開始 LED は強く（kcheck の `led_peak_count` ≥ 1000）。左カメラの ROI に照明の反射の輝点が入らないことを最初に確認（V15c の 18:35 走査で LED を取り違えた）。
- 電流の見張り 3 % は残す。温度は 10〜15 分ごと。

## 乱数の設計の扱い

- `random_*`（5〜40 / 30 / 20 Hz の多正弦、面内 rms 3 / 6 / 10 mm）と `aug_random_*`（8 月の長い乱数を ±15 mm に縮尺）には周期が無いので、評価は 0.5〜7.5 s の全区間。
- 線形模型（冷却後の値）でのトラップからのずれは最大 1.1 mm（`random_rms6_5-30Hz_seed1`）で線形域（2 mm）の内。粒子が落ちたら同じ設計を 1 本だけ撮り直し、2 回落ちたら飛ばす。
- 取り込みは `kind: imported`、`reference = reference_mm`（ff_heart_15V と同じ）。session JSON に `design_dir = ff_diverse`。

## 解析（Mac・dng・Miyabi）

1. 取り込み: `nn_embed/data.py` の分類に `ff_diverse` の run 名（`random_*`、`eight_v_*`、`infinity_*`、`rect14x10_*`、`tri14_*`、`helix_*`、`aug_*`）を足す。周期の無い設計は「整数ループ」の評価を外し、全区間の rms にする。
2. 分割: ff_diverse は原則すべて学習に入れる（検証は V15c の円 s20・リサージュ s15、試験は a10・傾いた円・3 次元リサージュ・ずらしたハートのまま）。学習軌道を増やす前後で検証の誤差がどう動くかを `compare.py` で比べる（同じ種・同じ設定）。
3. 乱数の設計は、周波数ごとの誤差（スペクトル）で模型の帯域の弱点を見る（`analysis/chirp_frf.py` の復調は使えないので FFT）。
